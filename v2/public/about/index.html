THE LITTLE COMPANION

嗨，我是小優！

一隻住在 LINE 裡，會陪你聊天、也會幫你找遊戲攻略的小傢伙。

01 ABOUT XIAO-YOU

從一段回憶，變成一個角色。

小優最初誕生的理由其實很單純。

牠的原型，是開發者曾經飼養過的一隻台灣喜鵲。那是一隻非常聰明、好奇心旺盛，又有點調皮的鳥，總是有自己的想法，也常常做出讓人又好氣又好笑的事情。

在牠離開之後，因為一直很懷念牠，所以便以牠為原型，重新設計出現在這個擬人化的「小優」。

黑白色系的外觀、活潑又帶點古靈精怪的個性，都來自對那段回憶的想像。
02 WHAT XIAO-YOU DOES

小優可以做什麼？

小優最早只是一個單純的 LINE 聊天機器人。

當時的想法是：

既然平常聊天、找資料、查遊戲攻略都會使用不同的工具，那能不能乾脆把這些事情集中在一個每天都會打開的地方？

於是，小優就住進了 LINE。

現在的小優主要有兩個功能。

TALK

•••

和小優聊天

直接傳送文字訊息，就可以和小優進行 AI 對話。

不用另外打開其他網站，也不用輸入複雜的指令，只要像平常傳 LINE 一樣跟牠說話就可以了。

有問題想問、想找人聊聊天，或者只是突然想到一些奇怪的事情，都可以丟給小優。

FIND

查詢遊戲攻略

這也是小優最初誕生時最重要的功能之一。

以前每玩一款遊戲，就會整理一份自己的攻略資料；遊戲越玩越多，Google 試算表也越開越多，最後連自己都開始找不到資料放在哪裡。

所以乾脆讓小優來找。

從 LINE 選單進入「遊戲攻略」，選擇遊戲與資料類型，再輸入想查詢的關鍵字，小優就會從整理好的攻略資料中找出對應內容。

不用記指令，也不用翻一大堆試算表。

03 THEN & NOW

小優以前不是現在這個樣子。

V1

小優的第一個版本其實是在好幾年前完成的。

當時只是抱著「能不能做出來」的想法，用 JavaScript、Google Apps Script、Google 試算表以及 LINE Messaging API，一點一點把聊天、攻略查詢和其他功能拼在一起。

程式沒有什麼漂亮的架構，甚至連 Framework 都沒有。

能跑，就很開心了。

…

隨著時間過去，原本使用的 API 逐漸停止服務，舊程式也慢慢失效，小優就這樣沉睡了一段很長的時間。

V2

直到最近，才決定把牠重新挖出來。

不是把舊程式勉強修到能跑，而是保留原本「聊天＋遊戲攻略助手」的想法，重新整理功能、資料與程式架構，讓小優以 V2 的形式重新回到 LINE。

04 STILL XIAO-YOU

為什麼還叫做小優？

因為這個名字從來就不只是某個軟體專案的名稱。

從最初那隻聰明又調皮的小鳥，到後來畫成角色，再到最後變成住在 LINE 裡的聊天機器人，小優其實一直都是同一個存在的延續。

程式可以重寫，功能可以改掉，使用的技術也會一直更新。

但牠永遠是那個小優。
